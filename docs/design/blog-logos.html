Logo options for the blog

Marks drawn from Bagel Fat One, the letterforms of the main site's logo. The first three put L, B and I (Laurence Bugasu Ininda) in one square with no border. Each shows the mark, the header lockup in light and dark, and the solid favicon in a browser tab.

The see-through mark is used in the page header, and the solid tile is the favicon and app icon. All six use the blog's orchid. The main site's mark is lilac, and either colour can be used for any of them.
