# Logo files

The blog's mark: a big L, a small B in the L's inner corner and an I standing to its right, one colour, no border. Source: the A2 option in [../blog-logos.html](../blog-logos.html), drawn from the Bagel Fat One letterforms.

| File | Use |
|---|---|
| `logo.svg` | Header mark on light pages (orchid `#9a3fc4`) |
| `logo-dark.svg` | Header mark on dark pages (`#c78bf0`) |
| `favicon.svg` | Browser tab icon, no background; switches colour with the system theme |
| `favicon-32.png` | Fallback tab icon |
| `icon-tile.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | App icons: the mark on a dark square (`#17112b`) |
| `icon-maskable.svg`, `icon-maskable-512.png` | Maskable icon with extra padding |
| `logo-sheet.png` | A preview of all of the above in context |
