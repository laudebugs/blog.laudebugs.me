# Standards

What good output looks like in this project. Standards differ from [guidelines](../guidelines/README.md): guidelines govern how we work, standards govern what we produce.

Open every standards doc with its scope (what it covers and does not) and "`AGENTS.md` takes precedence". Tag each rule **(Current)** (enforced today) or **(Target)** (new code follows it; old code migrates when next touched, no drive-by rewrites).
