# Contributing

- **One branch and one PR per piece of work**, in its own git worktree. See [docs/guidelines/git-workflow.md](docs/guidelines/git-workflow.md).
- Run `make check` before you push. CI runs the same.
- Every PR implements a todo from [docs/todos/ready/](docs/todos/ready/), except the exemptions listed in [docs/todos/README.md](docs/todos/README.md).

The full rules live in [AGENTS.md](AGENTS.md).
